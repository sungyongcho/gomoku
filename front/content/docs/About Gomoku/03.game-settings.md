# Game Settings

<div class="diagram-embed-wrap"><Diagram38 /></div>

The settings dialog has the options below. Settings that only matter for one engine, or only when captures are on, are hidden when they do not apply.

| Setting | What it does | Default |
|---|---|---|
| **AI model** | Picks the engine you play against: `minimax` or `alphazero`. | `minimax` |
| **Difficulty** | How strong `minimax` plays. `easy` searches 5 moves ahead, `medium` searches as deep as it can in 0.4 seconds, and `hard` searches 10 moves ahead with a more detailed evaluation. Not shown for `alphazero`. | `hard` |
| **First move** | Which player moves first. The first player is **Black** (`X`, the dark stone); the other is **White** (`O`, the light stone). | `Player1` |
| **Enable Double-Three Prohibition** | Forbids moves that make two open threes at once. | on |
| **Enable Capture** | Turns capturing pairs of stones on or off. The two settings below appear only when this is on. | on |
| **Total of captured pair stones** | How many pairs a player must capture to win, from 3 to 7. | 5 |
| **Player1 Advantage** / **Player2 Advantage** | How many captured pairs each player starts with, from 0 up to one less than the capture goal. Both go back to 0 when the capture goal changes. | 0 |

Right-click evaluation of a point works only with `minimax` (see [Evaluation Tool](/docs/about-gomoku/features#evaluation-tool-minimax-mode-only)).

> **Note:** The AlphaZero engine plays only the default rules, so in `alphazero` mode **First move** is the only setting you can change. Double-three prohibition and captures stay on, the capture goal stays at 5 and both advantages stay at 0.

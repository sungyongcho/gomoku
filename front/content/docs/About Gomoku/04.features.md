# Features

## History Mode

Navigate through previous moves without affecting the current game state. Toggle history mode via the **History** button in the sidebar, then use **Prev** / **Next** below the board to step through the move sequence.

## Undo Turn / Undo Move

Use the undo button to revert recent actions. The behavior adapts to the game mode:

| Mode              | Button label      | Behavior                                         |
|-------------------|-------------------|--------------------------------------------------|
| Player vs AI      | **Undo a turn**   | Rewinds both your last move and the AI's reply (available only when you move first as Black) |
| Player vs Player  | **Undo a move**   | Rewinds only the most recent move                |

## Evaluation Tool *(minimax mode only)*

Right-click an empty point to see how good it is. The minimax engine scores that point for both players and shows the result as a percentage for each side. This works on desktop only, since touch screens have no right-click.

### Why AlphaZero mode has no evaluation

AlphaZero could evaluate a point in two ways, and neither is worth it:

- **Ask the neural network once.** This is fast, but it is a guess without looking ahead. The AI never plays on this guess alone: it runs hundreds of searches before each move. In testing, the guess often called a point good, and the AI's reply then showed it was not.
- **Run a short search, the way the AI picks its own moves.** This answer can be trusted, but every click would take search time on the server's two CPU cores. The server uses those same cores to keep thinking about your game while you choose your move, so each evaluation would make the AI's next move weaker and slow down other players' games.

## Export / Import

The sidebar provides two ways to save and share game state:

- **URL** — encodes the current board state as a base64 URL and copies it to the clipboard. Opening the URL in a browser restores the game state automatically.
- **JSON** — downloads the full game state (board, move history, settings) as a `.json` file.

The JSON format is shared across the application: exported files can be used as [test cases](/docs/about-project/debug-and-testing#adding-a-new-test-case) for AI regression testing, and the test page's **debug** button opens a test case in the [debug page](/docs/about-project/debug-and-testing) for inspection.

## AI Response Time

In Player vs AI mode, the sidebar shows the average AI response time over the AI moves of the current game (**AI avg**), displayed at the bottom of the game history panel. This is computed from the `executionTime` field returned with each AI move (see [WebSocket JSON Protocol](/docs/about-project/websocket-json-protocol)).
